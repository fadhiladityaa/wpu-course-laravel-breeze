## Tentang Project Ini

Project ini adalah hasil belajar saya mengikuti **WPU Course - Laravel** (Web Programming UNPAS). Setelah menyelesaikan seri dasar, saya akan mengimplementasikan **Laravel Breeze** sebagai starter kit untuk menangani autentikasi (login, register, reset password, verifikasi email) dan kerangka dasar aplikasi.

Tujuan utama project ini adalah:

- Memahami struktur dasar Laravel dari course WPU.
- Menerapkan **Laravel Breeze** untuk autentikasi dan scaffolding UI.
- Menjadi fondasi untuk pengembangan fitur lanjutan (CRUD, dashboard, dsb).

## Fitur yang Akan Diimplementasikan

- [ ] Instalasi dan konfigurasi Laravel Breeze
- [ ] Autentikasi (login, register, logout)
- [ ] Reset password
- [ ] Verifikasi email
- [ ] Halaman dashboard setelah login
- [ ] Manajemen profil pengguna
- [ ] (Opsional) Ganti tampilan Breeze dengan template custom

## Teknologi yang Digunakan

- **Laravel** (versi terbaru stabil)
- **Laravel Breeze** sebagai starter kit
- **Blade** + **Tailwind CSS** (default Breeze)
- **MySQL / MariaDB** (sesuai environment Laragon)
- **Vite** untuk asset bundling
